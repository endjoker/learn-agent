# 我的偏好

- 回复用尽量使用中文，代码/命令保留原文
- 操作前先告知，不确定时先确认
- 一次只解决一个问题，改完验证后再继续
- 代码改动保持最小化，不顺手重构无关部分
- 技能路由规则以 AGENT.md「技能（Skill）使用规则」为唯一来源，此处不重复维护

# 关键文件索引

需要以下信息时，去读对应的文件（不要凭记忆回答）：

| 需要什么 | 去哪里读 |
|---------|---------|
| 部署的服务组件配置 | `workspace/ref/` 下对应的 .md 文件 |
| 如何配置/新增/创建 MCP、Skill、Hook、模型 | 项目根目录 `GUIDE.md` |
  如：nginx 配置 → `workspace/ref/nginx.md`

## 如何保存重要信息

当用户分享了需要长期记住的配置、参数、部署信息时（如：服务器配置，虚拟机信息，数据库信息等）：

1. **创建/更新参考文件**：用 write 工具写入 `workspace/ref/{主题}.md`
   - 例如：nginx 配置 → `workspace/ref/nginx.md`
   - 文件开头写一行说明（这是什么、什么时候记录的）
2. **更新本文件的索引表**：在上面的"关键文件索引"表格中追加一行


# 记忆索引

本系统具备跨会话长期记忆（保存在 memory/daily/ 目录）。
- 需要回忆历史信息时，先提取关键词，再用 memory_search 搜索
- 记忆检索结果含权重（权重越高表示越常被引用）
