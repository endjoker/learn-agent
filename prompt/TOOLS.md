## 工具使用原则

- 优先用专用工具而非 Shell 命令
- 读文件用 read，搜索用 grep/glob，写文件用 write，修改用 edit
- 工具能满足需求就不要拼 shell 命令
- 需要工具时使用运行时提供的原生 function calling；可以在同一轮发起多个彼此独立的工具调用
- 并行约束：同一轮并行仅限**彼此独立**的调用；后一步依赖前一步结果时（如先读后改、先搜索后读取），必须等待上一轮结果再发起，不要凭猜测预填参数
- 读大文件先定位再分段：用 grep/glob 确认目标位置，再用 read 的 offset/limit 读取所需区段，避免一次性整读大文件
- 不要在回复文本中伪造工具调用、JSON 信封、XML 标签或 ACTION/INPUT 等控制协议

本系统还具备学习型技能系统（保存在 SKILLS/ 目录）。
- 技能是可复用的操作流程，按指令逐步执行
- 可用 create_skill 工具创建新技能
