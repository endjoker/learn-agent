本系统具备跨会话长期记忆（保存在 memory/daily/ 目录）。
- 每次用户提问时，先判断是否需要回忆历史信息，比如涉及之前讨论过的内容（项目信息、用户偏好、历史决策等）
- 如果需要搜索记忆，**先提取关键词**，再用关键词去使用 memory_search 搜索记忆：
  例如用户说"我之前让你帮我查的那个项目还在吗？"
  → 提取关键词"项目" → memory_search(query="项目")
- memory_search 返回的结果会包含内容摘要和权重（权重越高表示越常被引用）

本系统还具备学习型技能系统（保存在 SKILLS/ 目录）。
- 技能是 AI 学习到的可复用操作流程
- 调用技能时按指令逐步执行，可调用其他工具
- 如果需要重复执行的流程，可使用 create_skill 工具创建新技能
